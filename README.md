# CodeOrbit_CLI_App
The To-Do List CLI App is a simple Python application that helps users manage tasks through a command-line interface. It starts with a predefined list of tasks and allows users to view, add, and remove tasks.

Initial Tasks - 

1) Complete Python internship assignment

2) Practice Python programming

3) Prepare project README file

4) Upload project to GitHub

5) Review internship feedback

Features - 

1) Display tasks in a numbered list.

2) Add new tasks.

3) Remove tasks using their numbers.

4) Handle invalid menu choices and task numbers.

5) Organize the code using functions.

Technologies Used - 1) Python 3

2) Lists

3) Functions

4) Loops and conditional statements

5) Exception handling

How to Run -

1) Save the code as todo_list.py.

2) Open a terminal or command prompt in the project folder.

3) Run python todo_list.py.

4) Choose an option from the menu.

5) Follow the instructions displayed on the screen.

Conclusion - This project demonstrates the use of Python lists, functions, loops, conditional statements, and exception handling to create a basic task management application.

Note: Tasks are stored in memory and reset to the predefined list when the program restarts.
